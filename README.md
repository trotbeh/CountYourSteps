# CountYourSteps

A 2D game made with Unity.

Every move is a step. The portal is ten steps away and your step counter keeps
draining — reach it before it hits zero.

## Play
[ITCH_IO_LINK](https://trot-beh.itch.io/countyoursteps)

## Status
Not finished yet. Currently working: main menu and core gameplay, and new features.

Working:
- Grid-based movement (WASD / arrow keys), one move = one tile
- Four-direction walk animations
- Step counter and lose condition when steps run out
- Win condition when you reach the portal
- Main menu and return-to-menu from the game (ESC + button)

Missing:
- Walls and collision
- Trap tiles that drain extra steps
- Win screen and restart flow
- Lose message
- Sound effects
- Build and itch.io testing

## Running it
Open the project in Unity 6000.3.24f1 and run the `Scenes/menu` scene.
